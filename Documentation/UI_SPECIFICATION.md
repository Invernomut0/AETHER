# UI Specification

## Main navigation
Overview, Effects, Animation Studio, Physics, Layouts, Workspaces, Rules, Performance, Diagnostics, Settings.

## Overview
- Runtime status
- Window discovery counts
- Permission states
- Active effects
- Capture sessions
- Renderer health
- Recent errors

## Effects Library
- Search and category filters
- Preview using synthetic fixture texture
- Effect details and parameter inspector
- Enable/disable and preset selection

## Animation Studio
- Timeline with tracks and keyframes
- Curve editor
- Effect layers
- Preview/play/stop
- Undo/redo
- Save/export declarative preset

## Performance
- Frame-time history
- FPS
- CPU and memory
- GPU timing where measurable
- Texture cache
- Capture queue depth and dropped frames

## Diagnostics
- Structured logs
- Event timeline
- Window capability inspector
- Overlay lifecycle
- Export redacted diagnostics

## Design
Premium macOS-native appearance. Prefer native controls, restrained material usage, accessible contrast and reduced-motion support. Visual effects must not compromise system usability.
